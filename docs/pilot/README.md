In the app:
- **Partners** send a weekly two-minute check-in: Help & support → Pilot check-in (web), or Account → Pilot check-in (mobile).
- **Unite** reads the results and sends reminders: Admin → Pilot feedback.

Nothing has been bought, registered or deployed. The decisions Unite Group needs to make are listed in section 1 of the checklist.
