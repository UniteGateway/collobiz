## Purpose patterns (Master Book §5)

- **content** — Provide readable content, search/filter where relevant, role-based actions, validation, clear status and user feedback.
- **admin-control** — Restrict to entitled administrators; record actions, approval reasons, previous values and actor/time.
- **ai-explainable** — Show matching rationale, filters, source attributes, uncertainty and a human accept/reject action; no automatic legal/financial decisions.
- **project-scope** — Show project/tender scope, deadlines, submissions, milestones, permissions, evidence and status updates.
- **commercial-record** — Show record ID, verified status, audit history, permissions, relevant documents, next action and precise commercial state.
- **identity-collaboration** — Show verified identity, capabilities, geography, invitation/approval controls, permissions and collaboration status.

All screens share the acceptance rule: *correct role can complete the primary action; unauthorized users cannot; failure and empty states are understandable; audit events are created for consequential changes.*

Mobile column: **native** = dedicated Expo screen; **responsive** = responsive web at 390/360 px; **desktop-admin** = admin portal (1440/1024/768).
